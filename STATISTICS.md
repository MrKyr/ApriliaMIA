## Trip Statistics

`trip_stats.awk` calculates statistics from the CSV telemetry files generated by `aprilia_to_csv.py`. It uses GNU awk and requires no additional Python packages.

### Stats

*stats.awk* sorts default by date

Pass the following options to sort by:

* distance
* duration
* fuel
* speed

ex. `awk -v sort=speed -f stats.awk Aprilia-Telemetry/trips-summary.csv`

### Individual trip

Pass a single trip CSV file to display its statistics:

```bash
awk -f trip_stats.awk Aprilia-Telemetry/103_2026-09-05_trip_1788639738971.csv
```

The report includes:

- Trip start and end times
- Distance and total duration
- Average speed and moving average speed
- Moving and stationary time
- Average fuel consumption in L/100 km
- Final fuel tank level
- Maximum speed and engine RPM
- Minimum and maximum battery voltage

### Combined statistics

Pass multiple trip CSV files to calculate statistics across trips longer than 2 km:

```bash
awk -f trip_stats.awk Aprilia-Telemetry/*_trip_*.csv
```

The combined report includes the number of qualifying trips, total distance and duration, overall and moving average speeds, total moving and stationary time, estimated average fuel consumption, maximum speed and RPM, and minimum and maximum battery voltage.

Only trips **longer than 2 km** are included in the combined report. Individual-trip reports have no such distance restriction.

### Graphs with *gnulot*

```bash
gnuplot -c trip_plot.gp Aprilia-Telemetry/013_2026-10-11_trip_1791716751658.csv
```

Open the resulting *png* file `trip_plot.png`

### Notes

- The script requires **GNU awk (`gawk`)**.
- Fuel consumption is reported in L/100 km, converted from the telemetry's average consumption in km/L.
- Combined fuel consumption is a distance-weighted estimate based on each trip's average consumption reading.
- Moving time is estimated from the recorded speed samples; stationary time is the remainder of the trip duration.
